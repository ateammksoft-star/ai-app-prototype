# AI上司・タスク管理アプリ

完了したタスクへのAIコメント機能と、タスクの登録・一覧表示機能を備えたプロトタイプです。

## 主な機能

- タスク名、詳細、期限日、優先度、担当者、ステータスの登録
- ステータス区分: 未着手、進行中、保留、完了
- SQLiteへの保存と、期限日順のタスク一覧表示（作成日を含む）
- 総タスク数とステータス別件数のダッシュボード
- 担当者・ステータス・優先度・期限日によるフィルター、タスク名・担当者による検索
- 作成日・更新日・期限日・優先度による昇順／降順のソート
- 一覧から選択したタスクの詳細表示（作成日・更新日を含む）
- 詳細画面からのタスク情報編集と更新日の記録
- タスク完了時の完了日時記録
- タスクごとのコメント・作業メモ（作業報告、引継ぎ、課題、備忘録）
- 確認ダイアログ付きタスク削除
- Geminiによる自然文からのタスク作成支援（登録前に内容を確認）
- 自然文検索、AI優先度提案、進捗・遅延リスク分析
- ダッシュボード分析、登録済みタスクとコメント履歴を参照するAIチャット
- 完了タスクへのAIコメント生成

## 起動方法

Python環境にFlaskとGoogle GenAI SDKをインストールし、Gemini機能を利用する場合は環境変数`GEMINI_API_KEY`を設定します。Gemini機能では、入力した内容やタスク・コメント情報がGoogle Gemini APIへ送信されます。

```bash
python -m pip install flask google-genai
python app.py
```

ブラウザーで`http://localhost:5000`を開きます。タスク登録にはAPIキーは不要です。タスク情報は`instance/tasks.db`に保存されます。

## Gemini機能

AI作成支援は入力案を登録フォームへ反映するだけで、自動保存しません。AI検索は自然文をステータス、優先度、担当者、タスク名、期限範囲へ変換します。優先度提案・進捗分析はタスクと直近コメントを、ダッシュボード分析は件数・率の集計を参照します。チャットには最大100件のタスクと各タスクの直近コメントを参照情報として渡します。AIの提案は内容を確認して利用してください。

## データ保持

タスクとコメントはSQLiteファイル`instance/tasks.db`に保存され、アプリの再起動後も保持されます。自動期限切れや自動削除はありません。タスクを明示的に削除すると、関連するコメントも削除されます。

`instance/`はGit管理対象外です。Codespaceやコンテナ自体を削除した後も保持するには、永続ストレージへの配置または定期バックアップが必要です。
